# التصوير | QDU

موقع اختبار مستقل لمادة التصوير مبني على قالب QDU 1.0.0. يوفّر اختبارات المحاضرات، وحفظ المحاولات محليًا، والمفضلة، ومراجعة الأخطاء والنتائج.

يتضمن **4 محاضرات و157 سؤالًا و601 اختيارًا** بالترتيب الوارد في المصدر.

## التشغيل المحلي

يتطلب Node.js 22 أو أحدث. من جذر المستودع شغّل:

```powershell
npm start
```

افتح عنوان المعاينة الذي يطبعه الخادم. يستخدم الاختبار المحلي المسار الفرعي `/qdu-imaging/`.

## الملفات والتحقق

- `site/data/subject.json` يضبط اسم المادة وهويتها. معرّف المادة `imaging` ومعرّف المستودع `qdu-imaging`.
- `site/data/lectures.json` يحفظ ترتيب المحاضرات، و`site/data/questions.json` يحفظ ترتيب الأسئلة والاختيارات ومفاتيح التصحيح.
- `site/data/enrichment.json` مخصص للترجمة والتلميح والتعليل عند توفرها في المصدر.
- `AUDIT.md` يسجل نتائج المطابقة وملاحظات المصدر.

شغّل `npm run validate` ثم `npm test`. وللتحقق قبل النشر استخدم `npm run validate -- --publish`.

## GitHub Pages

اختر GitHub Actions كمصدر النشر في إعدادات Pages، ثم أضف متغير المستودع `QDU_PUBLISH` بالقيمة `true`. يختبر مسار العمل التغييرات ويفحص بنية البيانات قبل تجهيز `site/` للنشر من الفرع الافتراضي.

## فحص واجهة الاختبار

يعزل `site/css/study.css` تخطيط الاختبار عن التنسيقات العامة. الأيقونات المحلية في `site/icons.svg`، وتبقى النصوص والبيانات منفصلة.

اختبار المتصفح الاختياري يحتاج Python مع حزمة Playwright ومتصفح Chromium مثبتين. شغّل الخادم ثم الفحص في نافذتين:

```powershell
node tools/serve.mjs 8098
python tools/browser_qa.py
```

يمكن تمرير عنوان معاينة آخر كوسيط. ينشئ الفحص جلسات معزولة لا تستخدم تقدم الطلاب، ويختبر الأحجام 320 و375 و768 و1280 و1920، والثيمين والترجمة والنصوص الطويلة والتنقل والحفظ والنتائج. بيانات النصوص الطويلة تُحقن داخل جلسة الاختبار فقط. الصور والتقرير في `test-results/visual/` مستبعدة من Git والنشر. لا يحل فحص Chromium محل اختبار أجهزة iOS وAndroid الفعلية أو سماع أصوات النظام.
